# Проверка реализации

Облачный проект: отдельная тестовая база Supabase `testing_14`. Проверка проведена 5 ноября 2026 года.

- Миграция применена к чистой схеме `public`; созданы четыре таблицы с RLS и семь публичных RPC.
- Supabase Security Advisor: замечаний нет.
- Открытая регистрация отключена. Прямой POST `/auth/v1/signup` возвращает `signup_disabled`; анонимные входы отключены.
- Подготовлены 2 постановщика, 2 исполнителя, 3 объекта и 8 задач во всех пяти статусах.
- `npm run build`: TypeScript и production-сборка проходят.
- `npm run test:api`: **14 групп, 257 проверок проходят**. Проверки авторизации выполняются с обычными токенами пользователей.
- Браузер: проверены вход и выход обеих ролей, список объектов и задач, история, форма возврата с запретом пустого комментария, недоступность чужой карточки по прямому URL. Мобильная вёрстка проверена при ширине 390 px.

Покрыты чтение чужих задач по UUID и через вложенные связи, объекты и история, полная матрица переходов/ролей, обязательный комментарий, запрет прямых изменений таблиц и истории, подмена авторов и ролей, переназначение, конкурирующая смена статуса и гонка создания задачи с удалением объекта. Временные объекты после проверки мягко удалены, демонстрационные задачи сохранены.

Performance Advisor на новой базе отметил неиспользованные пока индексы. Это информационное замечание для базы без рабочей нагрузки; индексы внешних ключей и выборки задач оставлены.
